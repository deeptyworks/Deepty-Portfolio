# Deepty Kumari Gupta — Personal Portfolio Website

A responsive personal portfolio website built with HTML5, CSS3 and vanilla
JavaScript for a BCA final-year project demonstration.

## Folder structure

```
portfolio/
├── index.html
├── style.css
├── script.js
├── README.md
└── images/
    ├── profile.jpg   ← main hero photo (square, at least 500x500px)
    └── about.jpg     ← photo used in the About section (portrait orientation works well)
```

## How to run it locally

1. Unzip / place the `portfolio` folder anywhere on your computer.
2. Add your two photos into the `images` folder, named exactly:
   - `profile.jpg`
   - `about.jpg`
3. Double-click `index.html` — it will open directly in your default browser.
   No server, installation or internet connection is required (except to load
   the two Google Fonts used for headings and body text).

## Sections

1. **Home** — introduction, photo, and call-to-action buttons
2. **About** — bio, education timeline, internship experience, certifications
3. **Skills** — categorized skill cards
4. **Projects** — this portfolio website (featured) and the Stock Market Trend Analysis project
5. **Contact** — contact details and a validated contact form (frontend-only, no backend)
